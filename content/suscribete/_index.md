# Sigue el caos con método

El símbolo de ondas es nuestro canal de **suscripción RSS**: sirve para recibir automáticamente las publicaciones nuevas de Cumstadística.

## La opción fácil

Copia esta dirección y añádela a tu lector de noticias favorito:

**https://cumstadistica.es/index.xml**

También puedes usar lectores como [Feedly](https://feedly.com/), [Inoreader](https://www.inoreader.com/) o cualquier aplicación compatible con RSS.

> Si no utilizas RSS, no pasa nada: siempre puedes volver a la portada para ver lo último.
